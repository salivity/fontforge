Active FontForge Forums and Mailing Lists

FontForge users seeking troubleshooting help, font creation advice, and software updates can connect through several active online spaces. While traditional email lists originally served as the core support channels, modern community interaction has largely shifted toward code repositories, specialized typography forums, and real-time chat networks. This guide outlines the most reliable and active mailing lists, community boards, and discussion platforms currently available for FontForge users.

GitHub Discussions and Issue Tracker

The primary and most active hub for FontForge user support and development is the official FontForge GitHub repository.

  • GitHub Discussions: The "Discussions" tab on the FontForge repository serves as the modern replacement for traditional web forums. Users can ask questions about installation, python scripting, glyph metrics, and general font generation workflows.
  • GitHub Issues: The "Issues" tab is strictly for reporting software bugs, crashes, and feature requests. It is monitored directly by current maintainers and active contributors.

SourceForge Mailing Lists

Historically, the official mailing lists hosted on SourceForge were the main method of community interaction. While activity has decreased in favor of GitHub, these archives and lists remain functional:

  • fontforge-users: Designed for end-user questions regarding font manipulation, formatting, and UI features.
  • fontforge-devel: Focused on the internal development of FontForge, C code modifications, and compilation issues.

Both lists maintain searchable public archives that contain years of troubleshooting solutions for obscure errors and edge cases.

TypeDrawers

TypeDrawers is a dedicated discussion forum for professional and amateur type designers. While it is not exclusive to FontForge, it features an active community of font creators. The forum includes software-specific threads where users regularly discuss FontForge alongside alternatives, share complex OpenType feature coding tips, and troubleshoot font production workflows.

IRC and Matrix Chat

For real-time assistance and live conversations with developers and advanced users:

  • Libera.chat IRC: The #fontforge channel on the Libera.chat network is the traditional real-time meeting place for developers and users.
  • Matrix: The IRC channel is bridged to the Matrix protocol, allowing users to join the conversation using modern Matrix clients such as Element.

Reddit Communities

For casual questions, file format troubleshooting, and font design feedback:

  • r/fontforge: A small, specialized subreddit dedicated entirely to the software.
  • r/typography and r/typedesign: Larger, highly active communities that often answer FontForge-related questions, especially regarding design principles, Bézier curve optimization, and font generation.
