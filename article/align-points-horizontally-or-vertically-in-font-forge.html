Align Points Horizontally or Vertically in FontForge

Aligning points horizontally or vertically in FontForge is essential for maintaining consistent stem widths, flat baselines, and sharp geometric curves. This guide explains how to quickly align multiple points using FontForge's built-in direction commands, the Average Points feature, and precise coordinate adjustments.

Method 1: Using "Make Horizontal" or "Make Vertical"

This method is the fastest way to align two or more adjacent points on the same path.

  1. Double-click your glyph in the Font View to open the Glyph Window.
  2. Select the Pointer tool from the toolbox (or press V).
  3. Select the points you want to align by holding Shift while clicking each point, or by dragging a selection marquee over them.
  4. Navigate to the top menu and select Point.
  5. Click Make Horizontal to align the selected points to the same Y-axis (horizontal line), or click Make Vertical to align them along the same X-axis (vertical line).

Tip: When you use this command, FontForge typically moves the second selected point to match the coordinate of the first.

Method 2: Using the "Average Points" Tool

If the points you want to align are not directly connected, or if you want them to meet at the mathematical midpoint rather than snapping to one specific point, use the Average Points tool.

  1. Select the points you wish to align across any part of the glyph contour.
  2. Go to the top menu and click Element > Average Points...
  3. In the dialog box:
    • Select Average X value if you want to align the points vertically.
    • Select Average Y value if you want to align the points horizontally.
  4. Click OK. All selected points will immediately snap to the calculated center coordinate.

Method 3: Manual Precision via Point Info

When you need multiple points to align to a specific, predetermined metric:

  1. Double-click the point that is positioned correctly to open the Point Info window.
  2. Note or copy the Base X value (for vertical alignment) or Base Y value (for horizontal alignment).
  3. Close the window, then open the Point Info window for the other point(s) you wish to align.
  4. Paste the copied coordinate into the corresponding X or Y field and click OK.
