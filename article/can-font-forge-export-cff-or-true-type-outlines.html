Can FontForge Export CFF or TrueType Outlines?

FontForge fully supports exporting fonts with both Compact Font Format (CFF) and TrueType outlines. This guide explains how FontForge handles cubic and quadratic curve formats, how to choose between them, and the direct steps required to generate .otf (CFF) or .ttf (TrueType) font files from your project.

Outline Formats in FontForge

FontForge is capable of creating and converting both primary digital outline types:

  • CFF (PostScript) Outlines: These use cubic Bézier curves (each curve segment has two control points). When compiled into OpenType fonts, these files typically use the .otf extension. CFF outlines are standard for graphic design, print workflows, and high-end typography.
  • TrueType Outlines: These use quadratic Bézier curves (each curve segment has one control point). When exported, these files typically use the .ttf extension. TrueType outlines are widely used for digital displays, operating system system fonts, and web fonts.

Internal Curve Modes vs. Export Formats

While FontForge can export to either format at any time, fonts internally store vectors in either cubic or quadratic mode:

  • To check or change your internal editing mode, navigate to Element > Font Info > Layers.
  • If you design using cubic splines and export to TrueType, FontForge will automatically convert the curves from cubic to quadratic.
  • If you design using quadratic splines and export to CFF, FontForge will convert them from quadratic to cubic.
  • For the cleanest rendering and file sizes, it is best to set your internal spline mode to match your intended export target before fine-tuning control points and hints.

How to Export CFF Outlines

To export a font with CFF outlines:

  1. Open your project in FontForge.
  2. Go to File > Generate Fonts...
  3. Choose the destination directory and name your file.
  4. Open the format dropdown menu under the file name.
  5. Select OpenType (CFF).
  6. Click Generate to save your .otf font file.

How to Export TrueType Outlines

To export a font with TrueType outlines:

  1. Open your project in FontForge.
  2. Go to File > Generate Fonts...
  3. Choose the destination directory and name your file.
  4. Open the format dropdown menu under the file name.
  5. Select TrueType.
  6. Click Generate to save your .ttf font file.

FontForge gives you complete control over font generation, allowing you to produce standard, production-ready fonts using whichever outline technology best matches your deployment needs.
