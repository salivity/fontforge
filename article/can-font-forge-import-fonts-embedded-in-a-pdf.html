Can FontForge Import Fonts Embedded in a PDF?

FontForge is capable of directly opening PDF files and extracting the fonts embedded within them. While this built-in feature allows users to inspect and recover typefaces stored in a document, the completeness and usability of the extracted font depend heavily on whether the original PDF embedded the full typeface or only a restricted subset of characters.

To open an embedded font in FontForge, navigate to File > Open, set the file type filter to display all files or PDF files, and select your target document. Once selected, FontForge analyzes the document and displays a dialog box listing every embedded font detected across the pages. You can then choose a specific font from the list, prompting FontForge to extract the glyphs and open the typeface in a standard editing window.

A common challenge when extracting fonts from PDFs is font subsetting. Most PDF creation tools embed only the specific characters used in the document to reduce file size. If a font is subsetted, FontForge will only import those specific glyphs, meaning the resulting font file will lack the rest of the character set, punctuation, or alternate weights.

Additionally, the quality of the imported font depends on how the font was initially embedded. FontForge handles standard PostScript (Type 1), TrueType, and OpenType (CFF) data effectively, retaining accurate vector outlines. However, if the PDF uses Type 3 fonts—which often represent glyphs as low-resolution bitmaps or complex PostScript drawing commands—FontForge may not be able to reconstruct standard scalable vector outlines cleanly. Encoding issues can also occur if the PDF lacks a proper "ToUnicode" mapping table, causing glyphs to appear correctly visually while being mapped to incorrect Unicode values.
