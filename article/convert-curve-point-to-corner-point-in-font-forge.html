Convert Curve Point to Corner Point in FontForge

In FontForge, switching a point from a smooth curve to an angular corner is an essential step for refining glyph outlines and controlling path direction. This guide explains how to identify curve points, change them to corner points using multiple quick methods, and adjust the resulting control handles to create sharp, precise angles in your font designs.

Understanding Point Types in FontForge

FontForge primarily uses three types of points to define vector outlines:

  • Curve points: Displayed as circles. Both control handles stay collinear (180 degrees apart) so that the line flows smoothly through the point.
  • Corner points: Displayed as squares. The incoming and outgoing handles can move independently, allowing for sharp angles.
  • Tangent points: Displayed as triangles. One side transitions smoothly into a straight line, while the other handles a curve.

Method 1: Using the Right-Click Context Menu

  1. Double-click the glyph you want to edit from the main FontForge font window to open the Glyph Outline view.
  2. Choose the Pointer tool (V on the keyboard) from the Tools palette.
  3. Right-click directly on the curve point (the circular point) you wish to change.
  4. From the context menu, select Make Corner (or navigate to Point Type > Corner depending on your FontForge version).
  5. The circular point will instantly change into a square, indicating it is now a corner point.

Method 2: Using the Point Info Dialog

  1. With the Pointer tool active, double-click directly on the curve point you want to convert. Alternatively, click the point once and press Ctrl + I (Windows/Linux) or Cmd + I (macOS).
  2. The Point Info window will appear displaying coordinates and point settings.
  3. Under the Point Type section, select the Corner radio button.
  4. Click OK to apply the change.

Method 3: Using the Element Menu

  1. Click on the curve point with the Pointer tool to select it. A selected point is highlighted in a distinct color (usually yellow or red depending on your theme).
  2. Go to the top menu and click Point (or Element > Point Info in older versions).
  3. Select Make Corner.

Adjusting Handles After Conversion

Once the point is converted into a corner point:

  1. Click on either of the two direction handles attached to the point.
  2. Drag the handle to adjust the curvature of that specific segment. Unlike a curve point, moving one handle will no longer move the opposite handle, allowing you to create sharp turns and hard edges.
