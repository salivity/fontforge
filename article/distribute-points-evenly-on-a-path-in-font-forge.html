Distribute Points Evenly on a Path in FontForge

FontForge does not feature a single native button to automatically distribute anchor points equidistant along an existing Bézier curve. However, you can achieve an even distribution of points by using built-in path discretization tools, FontForge's integrated Python scripting engine, or Spiro curve conversion. This guide covers the most direct methods to calculate, redistribute, and balance anchor points along any glyph path.

Method 1: Using the Python Scripting Engine

The most precise way to place points at mathematically even intervals along a path is via FontForge’s built-in Python interpreter.

  1. Open your font file and double-click the glyph you want to modify.
  2. Navigate to File > Execute Script... from the main menu.
  3. Paste a Python script that iterates over the active layer's contours, evaluates the spline length, and recalculates coordinates at fixed increments. For a basic equidistant subdivision on a selected layer:

Method 2: Spiro Mode for Geometric Balancing

If your goal is visual consistency and even curve tension rather than strict mathematical millimeter-spacing, switch to Spiro mode.

  1. Open the glyph in the Char View window.
  2. Select the entire contour or path you want to smooth.
  3. Click the Spiro toggle icon in the tool palette (or press Point > Spiro mode).
  4. Delete unnecessary intermediate points along the segment. Spiro automatically recalculates the curve tension across the remaining anchors, distributing curvature and virtual tension evenly between endpoints.
  5. If additional points are needed, select the Point Addition Tool, and click along the Spiro path. Spiro will continuously rebalance the spacing and curvature as you add them.
  6. Once balanced, exit Spiro mode to convert the path back into standard Bézier splines.

Method 3: Add Extrema and Midpoints

For traditional typographic workflow where points must align cleanly to axes:

  1. Select your path in the glyph edit window.
  2. Go to Element > Add Extrema (shortcut: Ctrl + Shift + X on Windows/Linux, Cmd + Shift + X on macOS). This places anchors at all vertical and horizontal maximums/minimums.
  3. For the spaces between extrema, use the Ruler Tool (K) to measure the distance between adjacent points.
  4. Double-click the path using the Add Point Tool at the exact midpoint indicated by the coordinates in the floating info window.

Method 4: External Pre-Processing via SVG

If you require precise algorithmic division of a complex vector path without coding:

  1. Copy the path or export the glyph layer via File > Export as an SVG.
  2. Open the SVG in vector software with built-in path subdivision (such as Inkscape’s Extensions > Modify Path > Add Nodes, set to a maximum segment length).
  3. Save the modified SVG and import it back into FontForge via File > Import.
