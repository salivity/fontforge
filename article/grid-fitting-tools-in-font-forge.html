Grid Fitting Tools in FontForge

FontForge provides built-in tools for grid fitting, allowing type designers to align vector outlines to pixel grids for optimal legibility at low screen resolutions. This article explains how FontForge handles grid fitting, how to preview rasterized glyphs across various pixel sizes, and how to utilize automated and manual hinting tools to control TrueType instructions.

Understanding Grid Fitting in FontForge

Grid fitting—commonly referred to in digital typography as hinting—is the process of adjusting the vector outlines of a font so that they align cleanly with the physical pixel grid of a display. FontForge supports grid fitting primarily through TrueType hinting instructions and PostScript hints. While PostScript hints rely mostly on the rasterizer to make rendering decisions, TrueType instructions allow font creators to control precise point movements, stem widths, and drop-out control directly.

How to Preview Grid Fitting

FontForge includes a dedicated display mode to visualize how your glyphs render at small sizes.

  1. Open a glyph in the Outline View.
  2. Navigate to View > Show Grid Fit.
  3. A dialog will prompt you to set the target point size and display resolution (DPI).
  4. Once enabled, FontForge overlays the rasterized pixels directly beneath your vector outlines, updating in real time as you adjust points or instructions.

You can also use the Metrics Window (Window > New Metrics Window) and change the display size to examine how multiple characters interact with grid fitting side by side at text sizes.

Automated Hinting and Instruction Generation

For quick optimization without writing low-level code, FontForge offers automated instruction tools:

  • Auto Hint: Accessible via Hints > Auto Hint, this command analyzes glyph geometry to automatically place horizontal and vertical hint stems.
  • Auto Instruction: Found under Hints > Auto Instr, this generates TrueType grid-fitting instructions based on the existing PostScript hints and font-level metrics. It ensures that stems, serifs, and baselines snap consistently to pixel boundaries across various sizes.

Manual TrueType Instruction Editing

For advanced users requiring precise control over rendering at specific pixel sizes, FontForge permits manual instruction editing:

  • Edit 'fpgm' and 'prep' Tables: Accessible through Font Info > TTF Values, allowing global font programs and pre-programs to be customized.
  • Edit Instructions: Located under Hints > Edit Instructions, this opens an assembly editor where you can write and modify low-level TrueType instructions (such as ALIGNRP, SHP, or DELTAP instructions) directly for individual glyphs.
  • Delta Instructions: FontForge supports delta hinting, which enables manual pixel adjustments at specific point sizes without affecting other rendering sizes.

Formats and Exporting Considerations

To preserve grid fitting behavior upon export, ensure you generate the font in a format that supports the instructions you created. TrueType (.ttf) files retain full low-level TrueType bytecode instructions, whereas OpenType with CFF outlines (.otf) relies on standard PostScript hint dictionaries. Before generating your final font files via File > Generate Fonts, ensure that hinting output is enabled in the font generation options.
