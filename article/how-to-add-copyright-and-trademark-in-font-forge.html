How to Add Copyright and Trademark in FontForge

Adding copyright and trademark notices to a font file embeds essential legal metadata directly into the software, establishing ownership and protecting intellectual property. In FontForge, this information is managed through the Font Info window across specific PostScript and TrueType metadata fields. Following the steps below will ensure your legal notices are properly integrated into your generated OpenType or TrueType fonts.

Step 1: Open the Font Info Window

  1. Launch FontForge and open your font project (.sfd file) or font binary.
  2. Go to the top menu bar and click Element.
  3. Select Font Info... from the dropdown menu, or press the keyboard shortcut Ctrl+Shift+F (Windows/Linux) or Cmd+Shift+F (macOS).

Step 2: Add the Copyright Notice

FontForge allows you to store the copyright notice in both PostScript and TrueType tables.

  1. In the left navigation pane of the Font Info dialog, click PS Names.
  2. Locate the Copyright field at the bottom of the tab.
  3. Enter your copyright text (for example: Copyright (c) 2026 Your Name. All rights reserved.).
  4. Next, click the TTF Names category in the left pane to ensure TrueType-compatible applications read the notice.
  5. Look for the entry with the name Copyright. If it exists, double-click it to edit. If it does not exist, click the Add or Append button, choose Copyright from the Name field dropdown, and input your text in the string box.

Step 3: Add Trademark Notices

Trademarks are stored in the OpenType/TrueType name table.

  1. While still inside the Font Info window, select TTF Names from the left pane.
  2. Check the list for an entry labeled Trademark.
  3. If the field is missing, click Append or Add.
  4. Set the name type to Trademark (OpenType Name ID 7).
  5. Enter your trademark statement into the text area (for example: FontName is a trademark of Your Company, Inc.).
  6. Click OK to save the changes and close the dialog.

Step 4: Save and Generate the Font

  1. Save your master file by navigating to File > Save.
  2. Go to File > Generate Fonts... to export your completed font format (such as .otf or .ttf).
  3. The generated font will now carry your embedded copyright and trademark metadata, which will appear in font viewers, design software, and operating system inspection tools.
