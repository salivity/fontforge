How to Adjust Baseline Offset in FontForge

Adjusting the baseline offset for specific characters in FontForge involves shifting the vertical position of individual glyph contours relative to the font's global baseline at the y=0 coordinate. This guide explains how to reposition single or multiple glyphs vertically using precise transformation values or manual adjustments, ensuring consistent vertical alignment across your typeface without altering global font metrics.

Understanding the Baseline in FontForge

In digital font design, the baseline is a fixed horizontal line located at Y = 0. You cannot move the baseline for an individual character directly; instead, you move the character's vector outlines above or below this Y = 0 line to achieve the desired offset.

Method 1: Precise Offset Using the Transform Tool

Using numeric transformations is the most accurate way to raise or lower specific glyphs by an exact number of units.

  1. Open your font project in FontForge.
  2. In the Font View window, click on the glyph you want to adjust. To select multiple characters, hold Ctrl (or Cmd on macOS) and click each character, or hold Shift to select a range.
  3. Navigate to the top menu and select Element > Transformations > Transform... (or press Ctrl+\).
  4. In the dialog box, set the dropdown menu to Move.
  5. Set the X value to 0 to keep horizontal positioning unchanged.
  6. Enter your desired vertical offset in the Y field:
    • Enter a positive number to raise the character above the baseline (e.g., superscripts or high punctuation).
    • Enter a negative number to lower the character below the baseline (e.g., subscripts or descenders).
  7. Ensure the transform origin is set appropriately (typically Glyph Origin), then click OK.

Method 2: Manual Adjustment in the Glyph Window

If you prefer visual adjustments, you can move outlines directly within the glyph editor.

  1. Double-click the glyph in the Font View to open the Glyph Window.
  2. Press Ctrl+A to select all points and contours within the glyph.
  3. Use the arrow keys to adjust the vertical position:
    • Press Up Arrow or Down Arrow to nudge by 1 unit.
    • Hold Shift while pressing an arrow key to move the selection in larger increments (typically 10 or 50 units, depending on your preferences).
  4. Monitor the coordinates in the top information bar to verify the new Y positions.

Method 3: Handling Accents and Composite Glyphs

If the character you are adjusting is a composite glyph (such as an accented letter made of a base letter and a diacritic reference):

  1. Right-click the character in the Font View and select Unlink Reference if you only want to shift the accent or the base independently without affecting the original source glyphs.
  2. Open the glyph and apply the vertical transformation specifically to the relevant contours.

Post-Adjustment Checks

After shifting glyphs vertically, verify your changes to maintain layout integrity:

  • Check Sidebearings: Ensure that moving the glyph did not unintentionally alter the left or right sidebearings.
  • Update Kerning: Verify that pairs involving the shifted glyph still align naturally with surrounding letters.
  • Test in Metrics View: Go to Metrics > New Metrics Window and type words containing the modified characters alongside standard baseline letters (like x and H) to evaluate alignment in real-time text strings.
