How to Adjust Cap Height and X-Height in FontForge

Adjusting the cap height and x-height in FontForge involves updating the font's OS/2 metric tables to ensure operating systems render text lines correctly, as well as setting horizontal guide lines for precise visual design. This guide provides clear, step-by-step instructions to configure both the internal font metadata and the visual workspace guides.

Step 1: Open Font Info

  1. Launch FontForge and open your font file (.sfd, .otf, or .ttf).
  2. Click on the Element menu in the top navigation bar.
  3. Select Font Info from the dropdown menu (or press Ctrl + Shift + F on Windows/Linux, Cmd + Shift + F on macOS).

Step 2: Set Metric Parameters in the OS/2 Table

The actual standard parameters used by rendering engines and applications are stored in the OS/2 table:

  1. In the Font Info window, look at the sidebar on the left and click on OS/2.
  2. Select the Metrics sub-tab at the top of the pane.
  3. Locate the X-Height and Cap Height input fields:
    • X-Height: Enter the vertical height (in font design units) from the baseline to the top of standard flat lowercase letters like "x", "v", or "z".
    • Cap Height: Enter the vertical height from the baseline to the top of flat uppercase letters like "H", "I", or "E".
  4. If you want FontForge to determine these values automatically based on your existing glyphs, click the Compute button next to each field (if available in your build) or check the automatic calculation options.
  5. Click OK at the bottom of the window to apply and save your changes.

Step 3: Add Visual Guide Lines (Optional but Recommended)

Updating the OS/2 table sets the metadata, but you should also add visual guidelines in the glyph editing window to help draw consistent shapes.

  1. Double-click any glyph (such as "x" or "H") in the main font view to open the Glyph Editing window.
  2. Ensure the horizontal ruler is visible at the top (toggle via View > Rulers if hidden).
  3. Click on the top horizontal ruler and drag a guideline downward onto the canvas.
  4. Release the mouse button near the intended height.
  5. Right-click the guideline and select Get Info (or double-click the guideline).
  6. In the dialog box, set the exact vertical position:
    • Enter your desired Cap Height value in the Y field and click OK.
    • Drag a second guide and enter your X-Height value in the Y field.
  7. To make these guides appear across all glyphs, right-click the guideline, open its properties, and set it to the Guide layer rather than a local layer.
