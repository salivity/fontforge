How to Adjust Tracing Threshold in FontForge

Converting bitmap images into clean vector glyphs in FontForge relies on external tracing utilities, typically Potrace or AutoTrace. This guide explains how to configure and adjust the bitmap-to-vector threshold settings directly within FontForge, allowing you to control edge sensitivity, capture fine details, and eliminate unwanted background noise when converting raster artwork into vector paths.

1. Identify Your Tracing Engine

FontForge does not contain an internal autotracer; instead, it delegates the conversion to an external program installed on your system.

  • Potrace: The standard tool for two-tone, high-contrast black-and-white images. Its threshold is controlled via the brightness/black-level argument (-k or --blacklevel).
  • AutoTrace: Better suited for multi-color or gray-scale bitmaps, controlled by color-count and threshold parameters.

2. Configure Tracing Arguments in Preferences

To adjust how strictly FontForge separates black pixels from white pixels during a trace:

  1. Launch FontForge.
  2. In the main menu, navigate to File > Preferences (on macOS, FontForge > Preferences).
  3. In the left-hand category tree, select Apps (or Generic, depending on your FontForge version).
  4. Locate the AutotraceArgs field.
  5. Enter the threshold flag appropriate for your tracing engine:
    • For Potrace: Use -k [value]. The value represents the black level threshold, ranging from 0.0 (all white) to 1.0 (all black). The default value is 0.5.
      • To capture lighter, fainter strokes: Increase the value (e.g., -k 0.65).
      • To ignore thin marks or reduce thickness: Lower the value (e.g., -k 0.35).
    • For AutoTrace: Use -color-count 2 -background-color FFFFFF along with any specific line-filtering flags depending on the desired sensitivity.
  6. Click OK to save and apply the changes.

3. Trace the Bitmap in the Glyph Editor

Once the threshold parameters are configured, run the trace on your glyph:

  1. Double-click a glyph slot in the font view to open the Glyph Window.
  2. Switch to the background layer by selecting View > Layers > Back (or clicking Back in the Layers palette).
  3. Go to File > Import, select your raster image (BMP, PNG, etc.), and place it into the canvas.
  4. With the background layer active, select Element > Autotrace.
  5. Switch back to the Fore (foreground) layer to view the newly generated vector outlines.

If the resulting vector contours are too thick, too thin, or retain too much noise, return to Preferences > AutotraceArgs, modify the -k threshold value up or down, and re-run Element > Autotrace until the vectors match your design specifications.
