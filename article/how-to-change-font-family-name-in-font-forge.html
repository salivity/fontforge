How to Change Font Family Name in FontForge

Changing the font family name in FontForge requires editing the font’s internal metadata rather than simply renaming the file on your computer. This guide provides a straightforward walkthrough on navigating to the Font Info dialog, updating both the PostScript and TrueType naming fields, and generating a newly named font file that operating systems and design software will recognize correctly.

Step 1: Open the Font Info Window

  1. Launch FontForge and open your font file (.ttf, .otf, or .sfd).
  2. Click on the Element menu in the top navigation bar.
  3. Select Font Info... from the dropdown menu (or press Ctrl + Shift + F on Windows/Linux, or Cmd + Shift + F on macOS).

Step 2: Edit the PostScript Names

  1. In the sidebar on the left of the Font Info dialog, ensure you are in the PS Names category.
  2. Locate the Family Name field and enter your desired font family name.
  3. Update the surrounding fields to match:
    • Fontname: The internal PostScript name, usually formatted without spaces (e.g., MyFont-Regular).
    • Family Name: The human-readable name of the font family (e.g., My Font).
    • Name for Humans: The full name displayed in general listings (e.g., My Font Regular).

Step 3: Update the TrueType Names

Most modern operating systems rely heavily on TrueType naming tables for menu display:

  1. In the left sidebar of the Font Info dialog, click on TTF Names.
  2. Look through the list for the entry with the Name ID Family (String ID 1).
  3. Double-click the string value and replace it with your new font family name.
  4. If present, update Preferred Family (String ID 16) and Full Name (String ID 4) to maintain consistency and avoid display errors across different applications.

Step 4: Apply and Export

  1. Click OK at the bottom of the Font Info window to apply your changes.
  2. Go to File > Generate Fonts... (or press Ctrl + Shift + G / Cmd + Shift + G).
  3. Choose your desired output format (TrueType or OpenType) and click Generate to export your newly named font file.
