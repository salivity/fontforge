How to Change PostScript Font Name in FontForge

Changing the PostScript font name in FontForge is essential for ensuring your font identifies properly across various operating systems, design applications, and PDF documents. This guide provides a quick, step-by-step walkthrough explaining where to access the font metadata settings, how to modify the PostScript name according to standard naming conventions, and how to save your updated font file.

Step 1: Open Your Font in FontForge

Launch FontForge and open the font file (.otf, .ttf, or .sfd) you wish to edit by navigating to File > Open.

Step 2: Open the Font Info Window

Once your glyph table loads, open the font metadata settings:

  • Click on the Element menu in the top toolbar.
  • Select Font Info... (or press the keyboard shortcut Ctrl + Shift + F on Windows/Linux, or Cmd + Shift + F on macOS).

Step 3: Locate the PS Names Section

In the sidebar on the left side of the Font Info dialog window, click on the PS Names category located under the general settings.

Step 4: Modify the PostScript Font Name

In the PS Names panel, locate the Fontname field. This field represents the internal PostScript name of your font.

When modifying this field, ensure you adhere to PostScript naming rules:

  • Do not use spaces.
  • Use only standard ASCII characters (alphanumeric characters, hyphens, and underscores).
  • Use standard naming conventions (e.g., MyFont-Regular or MyFont-Bold).

(Optional: You can also update the Family Name and Name for Humans in this same window to match your new font identity).

Step 5: Save and Apply the Changes

Click the OK button at the bottom of the Font Info window to save your new configuration.

Step 6: Generate the Updated Font

To export your modified font with the new PostScript name:

  1. Go to File > Generate Fonts...
  2. Choose your preferred font format (such as OpenType CFF or TrueType).
  3. Select an output directory and click Generate.
