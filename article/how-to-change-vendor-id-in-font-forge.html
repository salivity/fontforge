How to Change Vendor ID in FontForge

This guide explains how to locate and modify the four-letter font vendor ID (achVendID) in FontForge. Changing this identifier ensures your font file correctly attributes the foundry or creator in the OpenType/TrueType OS/2 table. The following steps show how to update the field in the font settings and generate the updated font file.

Step 1: Open Font Info

  1. Launch FontForge and open your font project (.sfd, .otf, or .ttf).
  2. In the top navigation menu, go to Element and select Font Info (or press Ctrl+Shift+F on Windows/Linux, Cmd+Shift+F on macOS).

Step 2: Navigate to the OS/2 Table

  1. In the sidebar on the left side of the Font Info window, click on OS/2.
  2. Locate the sub-tabs at the top of the pane and select Misc.

Step 3: Modify the Vendor ID

  1. Locate the field labeled Vendor ID.
  2. Enter your four-character code. The code must be exactly four ASCII characters long (case-sensitive). If your code contains fewer than four characters, pad the remainder with trailing space characters.
  3. Click the OK button at the bottom of the window to apply your changes.

Step 4: Save and Generate the Font

  1. Go to File > Save to update your working .sfd source file.
  2. Go to File > Generate Fonts... to re-export the final .otf or .ttf file with the updated vendor ID embedded into the font binaries.
