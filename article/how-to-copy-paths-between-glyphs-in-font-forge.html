How to Copy Paths Between Glyphs in FontForge

Yes, you can easily copy paths between different glyph windows in FontForge using standard clipboard operations. This article covers the step-by-step process of copying and pasting vector outlines across multiple glyph windows, how coordinate positioning is handled during the transfer, and important layer considerations to keep in mind.

Step-by-Step Guide to Copying Paths

  1. Open the Glyphs: In your main Font View, double-click the glyph containing the path you want to copy. Then, double-click the destination glyph. Both glyphs will open in their own Outline editing tabs or windows.
  2. Select the Path: In the source glyph window, choose the Pointer tool from the tool palette (or press V). Click on the specific contour to select its points, drag a selection box around the path, or press Ctrl + A (Windows/Linux) or Cmd + A (macOS) to select all paths in the layer.
  3. Copy the Selection: Press Ctrl + C (or Cmd + C), or select Edit > Copy from the top menu.
  4. Paste into the Destination: Switch to the target glyph window and press Ctrl + V (or Cmd + V), or select Edit > Paste. The copied paths will immediately appear in the target window.

Position and Coordinate Handling

When you paste a path into another glyph, FontForge places it at the exact same X and Y coordinates relative to the origin (0, 0) and baseline as it occupied in the original glyph.

If the path needs repositioning in the new glyph:

  • Select the pasted path using the Pointer tool and drag it manually.
  • Nudge the path using the keyboard arrow keys for fine adjustments (hold Shift for larger increments).
  • Use Element > Transformations > Transform to move the path by exact numerical units.

Layer and Direction Considerations

  • Active Layer: FontForge copies from and pastes into the currently active layer. Ensure you have the same layer selected—typically the Fore (Foreground) layer—in both the source and target windows before copying and pasting.
  • Path Direction: If you paste a contour into a glyph that already contains existing paths (for example, creating a composite character or an inner counter), verify the path directions. Choose Element > Correct Direction (Ctrl + Shift + D or Cmd + Shift + D) to prevent fill conflicts or rendering errors.
