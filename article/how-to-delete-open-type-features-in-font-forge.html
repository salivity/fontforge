How to Delete OpenType Features in FontForge

Removing unwanted OpenType features in FontForge allows font creators to eliminate unnecessary layout tables, reduce font file sizes, and resolve conflicting glyph behaviors. This step-by-step guide explains how to access FontForge's Font Info panel, locate specific GSUB or GPOS lookups, and safely remove the OpenType feature definitions you no longer need.

1. Open the Font Info Window

Launch FontForge and open the font file you wish to modify. Once the glyph grid loads:

  • Click on Element in the top menu bar.
  • Select Font Info (or use the shortcut Ctrl+Shift+F on Windows/Linux, Cmd+Shift+F on macOS).

2. Navigate to the Lookups Section

In the left sidebar of the Font Info dialog, click on Lookups. OpenType features are managed as lookups divided into two primary categories:

  • GSUB (Glyph Substitution): Handles features that swap glyphs, such as standard ligatures (liga), discretionary ligatures (dlig), small caps (smcp), and stylistic alternates (salt).
  • GPOS (Glyph Positioning): Handles features that adjust glyph placement, such as kerning (kern) and mark-to-base positioning (mark).

Select the tab (GSUB or GPOS) corresponding to the feature you want to remove.

3. Locate the Unwanted Feature

Browse the list of lookups displayed in the table. Lookups are often organized hierarchically:

  • Lookups display the OpenType feature tag (e.g., 'liga' Standard Ligatures) in the table columns or nested beneath the lookup name.
  • Click the small triangle or plus icon next to a lookup name to expand it and reveal its associated subtable and feature tags.

4. Delete the Feature or Lookup

Depending on whether you want to remove an entire lookup or just unlink a specific feature tag:

  • To delete the entire lookup and its rules: Select the lookup row, then click the Delete Lookup button on the right side of the window. FontForge will prompt you to confirm the deletion.
  • To remove only the feature tag while keeping the lookup: Select the lookup, click Edit Metadata, navigate to the feature list, select the specific tag you want to discard, and remove it from the lookup's assigned features.

5. Apply the Changes

Click the OK button at the bottom of the Font Info window. FontForge will apply the changes to the project.

6. Generate the New Font File

Changes made in the Font Info panel are not finalized in the compiled binary until you export:

  • Go to File > Generate Fonts...
  • Choose your desired export format (e.g., OpenType CFF or TrueType).
  • Select the destination directory, name the file, and click Generate.
