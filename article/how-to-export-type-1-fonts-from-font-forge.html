How to Export Type 1 Fonts from FontForge

Exporting a font as a Type 1 PostScript font in FontForge involves preparing your glyph outlines, verifying standard PostScript font metrics, and using the "Generate Fonts" dialog to output the files. This guide walks you through the exact steps to configure your settings and export your typography project into either binary (.pfb) or ASCII (.pfa) Type 1 format.

Step 1: Prepare Your Outlines

Before exporting to PostScript Type 1, ensure your glyphs meet standard PostScript requirements:

  1. Open your project in FontForge.
  2. Select all glyphs by pressing Ctrl + A (or Cmd + A on macOS).
  3. Correct the path directions by navigating to Element > Correct Direction.
  4. Remove overlap issues by selecting Element > Overlap > Remove Overlap.
  5. Ensure your font uses a 1000-unit Em size, which is standard for PostScript fonts. Go to Element > Font Info > General and verify the Em Size is set to 1000.

Step 2: Configure Font Information

Type 1 fonts require specific naming conventions without spaces in technical fields:

  1. Go to Element > Font Info.
  2. Under the PS Names tab, verify the following fields:
    • Fontname: The internal PostScript name. Do not include spaces or special characters (e.g., MyFont-Regular).
    • Family Name: The name of the font family (e.g., MyFont).
    • Weight: The style weight (e.g., Regular, Bold).
  3. Click OK to save changes.

Step 3: Open the Generate Fonts Window

  1. Navigate to the top menu and select File > Generate Fonts... (or press Ctrl + Shift + G / Cmd + Shift + G).
  2. Choose the destination directory where you want to save the exported font files.

Step 4: Select the Type 1 Format

  1. Locate the file type dropdown menu beneath the file browser.
  2. Select one of the Type 1 options:
    • PostScript Type 1 (Binary): Generates a .pfb file, commonly used in Windows and Unix environments.
    • PostScript Type 1 (ASCII): Generates a .pfa file, typically used in Unix printing environments.
  3. Next to the file format dropdown, click the Options button if you need to generate font metrics:
    • Check AFM to generate an Adobe Font Metrics file (.afm), which is often required alongside Type 1 fonts to store kerning and spacing data.
    • Click OK.

Step 5: Generate and Export

  1. Verify the filename in the text field at the top of the dialog.
  2. Click the Generate button.
  3. If FontForge detects minor technical errors (such as missing points or intersecting coordinates), a warning dialog will appear. Review the warnings and select Generate to proceed with the export.

FontForge will compile the font and output your .pfb or .pfa file, along with the corresponding .afm file, to the selected folder.
