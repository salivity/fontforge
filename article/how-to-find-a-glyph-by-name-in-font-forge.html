How to Find a Glyph by Name in FontForge

Finding a specific glyph in a massive font file can be tedious when scrolling manually. FontForge provides a built-in search tool called the "Goto" function, allowing you to instantly locate and highlight any character by typing its PostScript glyph name. This guide explains how to quickly search for glyphs by name using keyboard shortcuts and menu navigation.

Using the Goto Tool

The fastest and most reliable way to jump to a specific glyph by its name is using the Goto dialog:

  1. Open your font project in FontForge to view the main Font View window (the grid of characters).
  2. Open the Goto dialog by selecting View > Goto from the top menu, or by pressing the keyboard shortcut:
    • Windows / Linux: Ctrl + Shift + >
    • macOS: Cmd + Shift + >
  3. In the dialog box that appears, select the Name option (or radio button).
  4. Type the exact name of the glyph you are searching for (for example, adieresis, ampersand, or copyright).
  5. Click OK or press Enter.

FontForge will instantly jump the grid display to the designated glyph and highlight it. Double-click the highlighted cell to open the glyph in the editing window.

Selecting Glyphs by Name or Wildcard

If you want to find multiple glyphs at once or do not remember the exact name, use the Select By Name feature:

  1. In the Font View window, navigate to Edit > Select > By Name... (or Select By Wildcard... depending on your FontForge version).
  2. Enter the glyph name or a wildcard pattern (such as a* to select all glyphs beginning with the letter "a").
  3. Click OK. FontForge will select all matching glyphs across the character map.

Important Naming Considerations

  • Case Sensitivity: Glyph names in FontForge are case-sensitive. Searching for A will return the uppercase letter, while searching for a will return the lowercase letter.
  • Standard Naming: FontForge generally uses standard PostScript naming conventions. For example, accented characters often follow the format of the base letter plus the accent name (e.g., eacute for é).
