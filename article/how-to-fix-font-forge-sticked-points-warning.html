How to Fix FontForge Sticked Points Warning

The "Sticked points" warning in FontForge indicates an error where two or more control handles or path nodes occupy the exact same spatial coordinates, creating collapsed Bézier paths. This article outlines why this geometry error happens during font development and provides practical, step-by-step methods to resolve it both automatically and manually to ensure clean font compilation.

Why the "Sticked Points" Warning Appears

In vector typography, outlines are defined by on-curve anchor points and off-curve control points (handles). A "sticked points" warning occurs when:

  1. Zero-Length Handles: An off-curve control handle is pulled directly onto its associated on-curve point, giving the handle a length of zero.
  2. Coincident Control Points: Two handles for adjacent curves sit precisely at the same coordinates.
  3. Overlapping Anchor Points: Two distinct on-curve points share the exact same X and Y position on the grid.

Rendering engines and font format specifications (OpenType, TrueType, and PostScript) struggle to calculate curvature mathematically when control vectors have no length or direction. This can cause rendering artifacts, hinting failures, or compilation errors when exporting to OTF or TTF formats.

Method 1: Automatic Fix via FontForge Validation

FontForge includes built-in tools to detect and repair geometry issues automatically:

  1. Open your font and navigate to the glyph producing the error, or select all glyphs in the font view with Ctrl+A (Cmd+A on macOS).
  2. Go to Element > Validation > Find Problems...
  3. In the dialog box, go to the Paths tab.
  4. Check the box for Check for control points which are stuck to points.
  5. Choose Fix instead of Error if you want FontForge to attempt an automatic repair, then click OK.

Method 2: Merge Overlapping Nodes with Simplify

If the stuck points are redundant anchor nodes:

  1. Open the affected glyph in the Glyph Edit window.
  2. Select the entire outline by pressing Ctrl+A.
  3. Go to Element > Simplify > Simplify (or press Ctrl+Shift+M).
  4. To remove stubborn micro-segments, run Element > Simplify > Simplify More to merge duplicate coordinates into single, clean nodes.

Method 3: Manual Adjustment

For high-precision design work where automatic tools might alter the shape of the curve:

  1. Open the glyph in the Glyph Edit window.
  2. Zoom in closely to the flagged coordinates indicated by the validation tool.
  3. If an anchor has a zero-length handle, click and drag the handle away from the node to give it direction, or right-click the point and change its type to a Corner point or a Line segment to eliminate the unnecessary Bézier handle entirely.
  4. If two on-curve points overlap, select one of the nodes and press Delete to remove the redundant point while maintaining the closed path.

Once adjusted, run Element > Validation > Validate to confirm the warning has cleared before generating your final font files.
