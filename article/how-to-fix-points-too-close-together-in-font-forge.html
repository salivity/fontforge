How to Fix Points Too Close Together in FontForge

The "points too close together" warning in FontForge occurs when vector nodes or control handles sit within an imperceptible distance of one another, often leading to rasterization glitches, validation failures, and bloated font files. This guide explains how to identify, resolve, and prevent this error using FontForge's built-in cleanup utilities, manual merging tools, and coordinate-rounding functions to ensure your outlines remain clean and production-ready.

1. Identify the Problem Nodes

Before making edits, locate the exact coordinates triggering the warning. Select your glyphs and navigate to Element > Validation > Find Problems. In the dialog box, go to the Points tab, check Points too close together, and set your desired threshold (typically between 1 and 3 font units). Running this check will flag every offending node directly in the glyph editor, marking them with an indicator so you can inspect them without guessing.

2. Run the Simplify Utility

The fastest way to clean up redundant points font-wide is automated simplification:

  1. Select the affected glyphs in the font view (or select all with Ctrl+A / Cmd+A).
  2. Go to Element > Simplify > Simplify (or use the shortcut Ctrl+Shift+M / Cmd+Shift+M).
  3. If minor irregularities persist, use Element > Simplify > Simplify More. In this menu, configure the error margin to a low value (e.g., 0.5 to 1.0 units) to remove extraneous points that lie on top of each other without distorting the curve shape.

3. Remove Overlaps

Imported vector graphics from programs like Illustrator or Inkscape often generate zero-length segments at path intersections. Run Element > Overlap > Remove Overlap (Ctrl+Shift+O / Cmd+Shift+O). This merges intersecting paths and automatically strips away microscopic segments created where outlines cross.

4. Manually Merge Offending Points

When automated simplification alters the shape of delicate curves, manual cleanup is required:

  1. Double-click the glyph to open the Outline View.
  2. Zoom in closely to the flagged location until the overlapping points become distinct.
  3. Select the two points by dragging a selection marquee over them.
  4. Go to Point > Merge (Ctrl+M / Cmd+M). FontForge will combine them into a single node while preserving the direction of the surrounding Bézier control handles.

5. Round Coordinates to Integers

Points placed at fractional coordinates can trigger proximity warnings when exported to formats that require integer grid units (like TrueType). Select the paths and choose Element > Round > To Int. This snaps all nodes and handles to whole units on the Em square, often snapping sub-unit point pairs into the exact same coordinate, which can then be instantly cleared using the standard Simplify command.
