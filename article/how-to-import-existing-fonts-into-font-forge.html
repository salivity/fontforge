How to Import Existing Fonts into FontForge

Importing an existing font into FontForge allows you to modify glyphs, adjust metrics, add new characters, or convert between different font formats. This guide outlines the exact steps to open your existing font files—such as TrueType (TTF), OpenType (OTF), or Web Open Font Format (WOFF)—directly in FontForge, troubleshoot common import warnings, and properly save your changes without corrupting the original design.

Supported Font Formats

FontForge natively supports a wide range of vector and bitmap font formats, including:

  • TrueType (.ttf)
  • OpenType (.otf)
  • PostScript Type 1 (.pfa, .pfb)
  • Web Fonts (.woff, .woff2)
  • SVG Fonts (.svg)
  • FontForge Spline Font Database (.sfd)

Step-by-Step Guide to Importing a Font

  1. Launch FontForge
    Open the FontForge application on your computer. By default, an Open Font dialog window appears upon launch. If FontForge is already running, navigate to the top menu and select File > Open.

  2. Navigate to Your Font Directory
    Use the built-in file browser to locate the folder containing your font.

    • Tip: If your font file does not appear in the browser, ensure the Filter dropdown at the bottom of the dialog is set to All Fonts or matches your specific file extension.

  3. Select and Open the File
    Click on the font file you wish to edit and click the Open button. FontForge will decompile the binary font data and load the glyph table into a new window.

Handling Import Warnings and Prompts

When opening compiled fonts (like TTF or OTF), FontForge automatically runs integrity checks. You may encounter the following dialogs:

  • Validation Errors / Non-Standard Tables: FontForge may display a warning about self-intersecting paths or missing standard tables. In most cases, you can click OK or Ignore to proceed into the workspace.
  • Bitmap Strikes Selection: If the font contains embedded bitmap strikes alongside vector outlines, FontForge will ask which strike sizes you want to load. Select your desired sizes or uncheck them to load outlines only.
  • TrueType Instructions (Hints): If prompted to keep or discard TrueType byte-code hints, choose to preserve them if you plan on generating a TrueType font, or discard them if you intend to re-hint or convert the font to OpenType (PostScript outlines).

Saving and Exporting Your Edits

Once the glyph table is visible, you can double-click any glyph to edit its paths, adjust kerning, or change font metadata under Element > Font Info.

To preserve your working project:

  • Save your working progress as an uncompiled project using File > Save As and choose the native Spline Font Database (.sfd) format. This retains all layers, guides, and metadata without re-encoding loss.
  • To export a usable font file for your operating system or web use, go to File > Generate Fonts, choose your desired output format (such as OpenType CFF or TrueType), and click Generate.
