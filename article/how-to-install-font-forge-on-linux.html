How to Install FontForge on Linux

FontForge is a powerful, open-source font editor that allows you to create, edit, and convert outline and bitmap fonts. This guide provides direct, step-by-step instructions to install FontForge across various Linux distributions using native package managers, Flatpak, and portable AppImages.

Installing on Ubuntu, Debian, and Linux Mint

FontForge is available in the default repositories of Debian-based systems. Open your terminal and run:

sudo apt update
sudo apt install fontforge

For the latest features, the FontForge team also maintains an official PPA for Ubuntu users:

sudo add-apt-repository ppa:fontforge/fontforge
sudo apt update
sudo apt install fontforge

Installing on Fedora

Fedora includes FontForge in its standard repositories. Install it via dnf:

sudo dnf install fontforge

Installing on Arch Linux and Manjaro

Arch Linux users can install FontForge directly from the official repositories using pacman:

sudo pacman -S fontforge

Installing via Flatpak (Universal)

If you prefer a sandboxed application or your distribution does not offer a current version, you can install the Flatpak package from Flathub.

  1. Ensure Flatpak is installed on your system.
  2. Run the following command:
flatpak install flathub org.fontforge.FontForge

To run FontForge via Flatpak:

flatpak run org.fontforge.FontForge

Using the AppImage (Universal)

The AppImage format allows you to run FontForge without system-wide installation:

  1. Download the latest FontForge .AppImage file from the official FontForge GitHub releases page.
  2. Open your terminal, navigate to the download folder, and make the file executable:
chmod +x FontForge-*.AppImage
  1. Launch the application by executing the file:
./FontForge-*.AppImage

Launching FontForge

Once the installation is complete, you can start FontForge either by typing fontforge in your terminal or by selecting the FontForge icon from your desktop environment's application menu.
