How to Install FontForge on macOS Using Homebrew

This guide explains how to install the open-source font editor FontForge on macOS using Homebrew. Homebrew serves as the primary third-party package manager for macOS, automating the download, compilation, and configuration of FontForge and its required dependencies. Below, you will find the direct terminal commands needed to install, launch, and update both the command-line and graphical versions of the software.

The Package Manager: Homebrew

Homebrew is the package manager that handles FontForge installation on macOS. It manages libraries like Python, FreeType, and Cairo automatically, ensuring that FontForge has all required components to run smoothly on modern versions of macOS.

Step 1: Install Homebrew (If Not Installed)

If Homebrew is not yet installed on your system, open the macOS Terminal and run:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Follow the on-screen prompts to complete the setup and add Homebrew to your system path.

Step 2: Install FontForge

Homebrew provides two distribution methods for FontForge depending on whether you need the command-line utility or the full desktop graphical application.

Option A: Install the Desktop Application (Recommended)

To install FontForge as a standard macOS application with a graphical interface, install the Homebrew Cask:

brew install --cask fontforge

Once the process finishes, FontForge will appear in your /Applications directory.

Option B: Install the Command-Line Tool

If you only require the command-line binary and Python scripting modules without the macOS application bundle, install the standard formula:

brew install fontforge

Step 3: Launching FontForge

  • GUI: Open Finder, navigate to Applications, and click FontForge, or launch it via Spotlight by pressing Cmd + Space and typing "FontForge".
  • Terminal: If you installed the formula or want to run scripts, execute:
fontforge

Updating and Uninstalling

To update FontForge to the latest version, run:

brew upgrade fontforge

(Use brew upgrade --cask fontforge if you installed the cask version.)

To remove FontForge completely:

brew uninstall fontforge

(Or brew uninstall --cask fontforge for the application bundle.)
