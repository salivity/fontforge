How to Localize Font Names in FontForge

Localizing font metadata allows your font's name, style, and copyright information to appear natively in different languages across various operating systems. This guide walks you through the step-by-step process of accessing the TrueType/OpenType Name table in FontForge, adding language-specific string entries, and exporting the finalized multilingual font files.

Step 1: Open Font Info

  1. Launch FontForge and open your font project (.sfd, .ttf, or .otf).
  2. From the top menu, navigate to Element > Font Info (or press Ctrl + Shift + F on Windows/Linux, Cmd + Shift + F on macOS).

Step 2: Access the TTF Names Table

  1. In the sidebar on the left side of the Font Info window, select TTF Names.
  2. This table displays the OpenType name table entries. By default, most entries will be set to the language English (US).

Step 3: Add a Localized Language Entry

  1. Click on the name field you want to localize (for example, Family or Fullname).
  2. Click the Add button at the bottom of the dialog or right-click an empty row in the list to create a new entry.
  3. In the Language column for the new row, click the dropdown menu and select the target language (for example, Japanese, French, or German).
  4. In the String column, enter the localized name translated into the selected language (e.g., your font family name in Japanese Kanji/Kana).

Key Metadata Fields to Localize

To ensure proper rendering in localized application menus, provide translations for the following Name IDs:

  • Name ID 1 (Family): The localized name of the font family.
  • Name ID 2 (Subfamily): The localized weight or style (e.g., "Gras" instead of "Bold" for French).
  • Name ID 4 (Fullname): The combined localized family and subfamily name.
  • Name ID 16 (Typographic Family): Recommended if your family exceeds standard four-style arrangements (Regular, Bold, Italic, Bold Italic).
  • Name ID 17 (Typographic Subfamily): The localized specific style variant for extended families (e.g., "SemiBold", "Light").

Step 4: Verify and Save

  1. Review the TTF Names list to ensure both the default English (US) fallback and your localized entries are present.
  2. Click OK at the bottom of the Font Info window to save your metadata changes.
  3. Save your source file by going to File > Save.

Step 5: Generate the Font

  1. Navigate to File > Generate Fonts...
  2. Choose your desired output format (such as OpenType (CFF) or TrueType).
  3. Ensure the export options preserve OpenType tables, then click Generate.

The generated font file will now dynamically present the translated name when installed on an operating system running under the configured locale.
