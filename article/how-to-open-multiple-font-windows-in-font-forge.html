How to Open Multiple Font Windows in FontForge

Working with multiple fonts simultaneously in FontForge is essential for comparing glyph sets, transferring vector outlines, and maintaining consistency across different weights and styles. This guide provides a straightforward overview of how to display several font windows at once using FontForge’s native interface, command-line arguments, and multi-instance launching techniques.

Method 1: Open Fonts from the File Menu

FontForge natively supports viewing and editing multiple font files in separate windows within the same session.

  1. Launch FontForge and open your primary font file.
  2. Click on the File menu in the top menu bar of the active Font View window.
  3. Select Open... (or press Ctrl + O on Windows/Linux, Cmd + O on macOS).
  4. Browse to your secondary font file, select it, and click OK.
  5. The second font will open in its own independent window rather than replacing the current one.

Repeat this process for as many fonts as your system memory can comfortably handle.

Method 2: Open Multiple Files via the Command Line

If you are working from a terminal, you can open multiple fonts at the same time by passing their file paths together.

  1. Open your terminal or command prompt.

  2. Run the fontforge executable followed by the paths to each font file:

    fontforge font1.ttf font2.otf font3.sfd

  3. FontForge will launch and generate an individual workspace window for each specified font.

Method 3: Launch Separate FontForge Instances

If you prefer to isolate your workspaces—such as keeping projects completely separated across different virtual desktops or monitors—you can launch distinct instances of the program.

  • Windows: Right-click the FontForge shortcut in your taskbar or Start menu and click FontForge again to launch a completely separate process, then open your font.
  • macOS: Open Terminal and run open -n -a FontForge to force the system to launch a separate application instance.
  • Linux: Launch FontForge multiple times from your application launcher or terminal by executing fontforge & for each instance.

Managing Multiple Open Windows

Once multiple font windows are open:

  • Use the Window menu at the top of the interface to view a list of all currently loaded fonts and switch between them instantly.
  • You can drag and drop glyphs directly from one font's glyph table to another to copy character outlines, metrics, and references.
