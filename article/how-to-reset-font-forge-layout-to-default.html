How to Reset FontForge Layout to Default

If your FontForge workspace has become cluttered, windows have disappeared off-screen, or toolbars are misplaced, you can restore the interface to its original state. FontForge does not include a single "Reset Layout" button within the application, but you can revert the interface back to its factory defaults by clearing the software's saved preferences file. This guide covers how to quickly locate and remove these configuration files across Windows, macOS, and Linux.

Step 1: Close FontForge

Before modifying any files, ensure FontForge is completely closed. If the application is running while you delete configuration files, it may overwrite your changes and restore the broken layout upon closing.

Step 2: Locate the Preferences Directory

FontForge saves your window coordinates, docking states, and user preferences in a file named prefs. Navigate to the directory corresponding to your operating system:

  • Windows:
    Press Win + R, type %appdata%\FontForge, and press Enter.
    (Path: C:\Users\<YourUsername>\AppData\Roaming\FontForge)

  • macOS:
    Open Finder, press Cmd + Shift + G, paste ~/.config/fontforge, and press Enter.
    (Note: Older installations may use ~/Library/Application Support/FontForge or ~/.FontForge)

  • Linux:
    Open your file manager or terminal and go to:
    ~/.config/fontforge
    (Older distributions may store this at ~/.FontForge)

Step 3: Remove the Layout and Preferences Files

Inside the FontForge directory, locate the file named prefs.

  1. Delete the file: Move prefs to the Trash/Recycle Bin, or simply rename it to prefs.bak if you want to keep a backup of your custom hotkeys or font generation settings.
  2. If you see files named HotKeys or general configuration caches and wish to perform a complete factory reset, you can delete the entire FontForge configuration folder instead.

Step 4: Relaunch FontForge

Start FontForge again. Because the application cannot find an existing prefs file, it will automatically generate a new one using default settings. All toolbars, font view windows, glyph editing palettes, and metric windows will return to their default positions and sizes.
