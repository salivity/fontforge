How to Save a FontForge Database File

Saving your work in FontForge as a database file ensures that all font metadata, layers, guides, and kerning pairs are preserved in their native, editable format. Unlike standard font files such as TTF or OTF, FontForge uses the Spline Font Database format (.sfd) as its primary working file. This guide covers the exact steps to save your font project as an SFD file using FontForge’s built-in tools and shortcuts.

Steps to Save an SFD File in FontForge

  1. Open the File Menu: In the main FontForge font view window, click on File in the top navigation bar.
  2. Select Save or Save As:
    • If you are saving a new project for the first time, click Save As....
    • If you are updating an existing project, click Save (or press Ctrl + S on Windows/Linux, Cmd + S on macOS).
  3. Choose the Destination: In the file browser dialog that appears, navigate to the folder where you want to store your project.
  4. Name Your File: Enter your preferred name in the file name field. FontForge will automatically append the .sfd extension.
  5. Confirm Format: Ensure the file type is set to **Spline Font Database (*.sfd)**.
  6. Click Save: Click the Save button in the lower right corner of the dialog to write the file to your disk.

Saving as a Multi-File Database (SFDIR)

FontForge also allows you to save your project as a directory of text files rather than a single large file. This format, known as Spline Font Database Directory (.sfdir), is ideal if you use version control systems like Git.

To save as an SFDIR:

  1. Go to File > Save As....
  2. In the file format dropdown, select **Spline Font Database (directory) (*.sfdir)**.
  3. Name the folder and click Save.

Difference Between Saving and Generating

  • Saving (File > Save): Creates or updates the native .sfd database file. This file contains your complete design workspace and is only meant to be opened and edited in FontForge.
  • Generating (File > Generate Fonts): Exports the project into usable desktop or web font files, such as TrueType (.ttf), OpenType (.otf), or WOFF (.woff). Generating does not save your FontForge workspace history or non-standard design layers, so you should always save an .sfd file before generating final font files.
