How to Set Manufacturer Name in FontForge

Configuring the Manufacturer Name field in FontForge allows you to embed your foundry or company name directly into a font's metadata. This guide walks you through navigating FontForge's Font Info settings, locating the OpenType/TrueType name records, modifying the Manufacturer Name attribute, and saving your changes to ensure proper attribution across operating systems and design software.

Step 1: Open Font Info

  1. Launch FontForge and open the font file you wish to edit (.sfd, .ttf, or .otf).
  2. Click on the Element menu in the top navigation bar.
  3. Select Font Info from the dropdown menu (or press Ctrl+Shift+F on Windows/Linux, Cmd+Shift+F on macOS).

Step 2: Navigate to the TTF Names Tab

  1. In the Font Info window, locate the category list on the left side.
  2. Click on TTF Names. This section controls the OpenType/TrueType name table entries, which software applications read to display metadata like designer, copyright, and foundry information.

Step 3: Edit the Manufacturer Name Field

  1. Look through the list of name records for the entry labeled Manufacturer Name (Name ID 8).
  2. Double-click the text field adjacent to "Manufacturer Name" under the appropriate language (typically English (US)).
  3. Type the name of your foundry, organization, or personal manufacturer name into the field.
  4. If the field is not present in the list, click the Add or Append button at the bottom of the table, select Manufacturer from the dropdown options, and enter your text.

Step 4: Apply and Save Changes

  1. Click the OK button at the bottom right of the Font Info dialog to apply your changes.
  2. Save your FontForge source file by going to File > Save (Ctrl+S / Cmd+S).
  3. To export the updated font binary, go to File > Generate Fonts..., select your desired format (such as TrueType or OpenType CFF), and click Generate.
