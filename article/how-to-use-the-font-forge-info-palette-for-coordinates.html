How to Use the FontForge Info Palette for Coordinates

The Info palette in FontForge is an essential floating tool for tracking real-time cursor positions, vector displacements, and point metrics. This guide explains how to enable the Info palette in the Glyph Outline window, interpret its coordinate readouts, and use it to measure distances and angles accurately while designing your font outlines.

Opening the Info Palette

  1. Open your font project in FontForge.
  2. Double-click any glyph in the Font View to open the Glyph Outline View.
  3. Go to the top menu and select Window.
  4. Click Info (or ensure it is checked). A small, floating dialog box will appear over your workspace.

Reading the Coordinate Data

The Info palette dynamically updates based on cursor movement and point selection. It displays several key metrics:

  • X and Y: Represents the absolute horizontal (\(X\)) and vertical (\(Y\)) positions of your mouse pointer or the currently selected point relative to the glyph's baseline origin \((0,0)\).
  • Δx and Δy (Delta values): Displays the horizontal and vertical distance from the last clicked point to the current position of the pointer.
  • Distance (Dist / r): Shows the direct, straight-line Euclidean distance between the last reference point and the current cursor location.
  • Angle (θ): Displays the angle of the current trajectory in degrees, measured relative to the horizontal axis.

Measuring Distances and Offsets

To measure the precise distance between two elements in a glyph:

  1. Click on the starting point or anywhere on the canvas to set a temporary origin.
  2. Move your cursor toward the target point without clicking.
  3. Observe the Δx, Δy, and Dist values in the Info palette to read the exact offset and length between the two locations.

Tracking Coordinates While Transforming Points

When manipulating nodes or handles:

  • Selecting Points: Clicking a single on-curve or control point immediately populates the \(X\) and \(Y\) fields with its exact design-unit coordinates.
  • Moving Elements: When you click and drag a point, the Info palette updates the Delta fields in real time, allowing you to move nodes by precise numerical offsets without guessing.
  • Arrow Key Nudging: Selecting a point and pressing the arrow keys moves the node by set increments. The Info palette reflects these changes instantly, making micro-adjustments straightforward.
