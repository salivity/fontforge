Measuring Distance Between Points in FontForge

FontForge provides a dedicated Ruler tool specifically designed to measure the distance, angle, and coordinate offsets between points within glyph outlines. This guide explains how to access and use the Ruler tool to verify precise metrics, check stem widths, and maintain consistent proportions throughout your type design projects.

The Ruler Tool

The primary utility for measuring distances in FontForge is the Ruler tool (also referred to as the Measure tool). When active, it allows you to click and drag across any part of the Glyph Editing window to instantly calculate the linear distance between two locations.

How to Access the Ruler Tool

  1. Open any glyph in the Glyph Editing window.
  2. Locate the floating Tools palette.
  3. Click the icon that looks like a small ruler. Alternatively, you can cycle through tools or activate it using its keyboard shortcut if configured in your preferences.

How to Measure Distance

  1. With the Ruler tool selected, position your cursor over the starting point or coordinate you wish to measure.
  2. Click and hold the left mouse button, then drag the cursor to the target point.
  3. As you drag, FontForge displays a temporary measurement line along with an informational readout.
  4. Release the mouse button to finish the measurement. The temporary line will disappear once you click again or switch tools.

Measurement Data Provided

While dragging the Ruler tool, FontForge provides several real-time values:

  • Distance (\(dx, dy\)): Shows the horizontal change (\(dx\)) and vertical change (\(dy\)) in font units between the start and end points.
  • Total Length: The direct, straight-line Euclidean distance between the two points.
  • Angle: The degree angle of the measurement vector relative to the horizontal baseline.

Alternative Precision Tools

For static point-to-point data without dragging:

  • Point Info Window: Select a point and press Ctrl + I (Windows/Linux) or Cmd + I (macOS) to view exact X and Y coordinates.
  • Transform Dialog: Accessing metric transformations under the Element menu can help calculate offsets across multiple selected nodes.
