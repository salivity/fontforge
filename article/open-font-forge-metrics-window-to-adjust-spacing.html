Open FontForge Metrics Window to Adjust Spacing

Adjusting the spacing between characters is a critical part of font design known as kerning and metrics editing. In FontForge, this process is managed inside the Metrics window, which allows you to view multiple characters side-by-side, modify side bearings, and fine-tune character pairs in real time. This guide covers how to select multiple glyphs and open the Metrics window to quickly correct character gaps.

Step 1: Select Your Characters in the Font View

Before opening the Metrics window, select the glyphs you want to adjust:

  1. Open your font project in FontForge so you are looking at the main Font View grid.
  2. Click on the first character you want to edit.
  3. Hold down the Shift key and click another character to select a continuous range of glyphs, or hold Ctrl (or Cmd on macOS) to select specific, non-adjacent glyphs.

Step 2: Open the Metrics Window

Once your desired characters are highlighted, open the window using either method:

  • Using the Menu: Navigate to the top menu bar, click on Metrics, and select New Metrics Window.
  • Using the Keyboard Shortcut: Press Ctrl + K (or Cmd + K on macOS).

The Metrics window will open, displaying the selected characters in sequence along a shared baseline.

Step 3: Enter Custom Text for Context (Optional)

You do not have to return to the Font View if you need to test other combinations:

  1. Click the text box at the top or directly in the display area.
  2. Type any combination of characters or words to test how your selected glyphs behave alongside common letters (such as "AV", "To", or "minimum").

Step 4: Adjust the Character Gaps

You can modify the spacing in two ways inside the Metrics window:

  • Graphical Adjustment: Click and drag the vertical lines flanking each character. The lines closest to the glyph represent its Left Side Bearing (LSB) and Right Side Bearing (RSB). Dragging the space between two specific characters creates or alters a kerning pair.
  • Numerical Adjustment: Use the editable numeric fields at the bottom of the window to type exact values for LBearing, RBearing, Width, or Kern.
