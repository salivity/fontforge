Quickest Way to Clear a Glyph in FontForge

This guide outlines the fastest methods to completely remove all outlines, references, and shapes from a glyph in FontForge. Whether working with a single character or multiple glyphs at once, you can wipe the contents clean within seconds directly from the main font grid or from within the glyph editor.

Method 1: Clear from the Font View (Fastest)

The absolute quickest way to clear a glyph without opening individual editor windows is from the main Font View (the grid showing all your font characters):

  1. Select the glyph: Click on the glyph you want to clear. To clear multiple glyphs simultaneously, hold Ctrl (or Cmd on macOS) while clicking individual glyphs, or hold Shift to select a range.
  2. Execute the Clear command: Press Ctrl + K (or Cmd + K on macOS). Alternatively, go to the top menu and select Edit > Clear.

This immediately deletes all foreground paths, background sketches, components, and references from the selected slots while preserving the glyph's encoding slot and metrics.

Method 2: Clear from the Glyph Outline View

If you already have the glyph editor open:

  1. Select all elements: Press Ctrl + A (or Cmd + A on macOS) to select all paths and points.
  2. Delete: Press the Delete key or Backspace.

Important Note: "Clear" vs. "Delete"

In FontForge, avoid using the Encoding > Detach & Remove Glyphs command if your intention is merely to wipe the vector drawing. Using Edit > Clear (Ctrl + K) safely removes the artwork while keeping the glyph's code point, slot, and width intact in your font table.
