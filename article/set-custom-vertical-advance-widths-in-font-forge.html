Set Custom Vertical Advance Widths in FontForge

Configuring vertical advance widths in FontForge is essential for creating fonts that support vertical writing modes, such as CJK (Chinese, Japanese, and Korean) scripts and traditional Mongolian. This guide outlines the exact process to enable vertical metrics in your font project, view vertical layouts, and define custom vertical advances (VWidth) for individual or batch glyphs.

Step 1: Enable Vertical Metrics in Font Info

Before setting vertical advance values, you must configure FontForge to support vertical metrics:

  1. Open your font project in FontForge.
  2. Navigate to the top menu and select Element > Font Info.
  3. In the sidebar of the Font Info dialog, click on General.
  4. Check the box labeled Has Vertical Metrics.
  5. Click OK to apply the changes.

FontForge will now compute and store vertical metrics tables (vhea and vmtx) upon font generation.

Step 2: Switch to Vertical Layout in the Font View

To view your glyphs with their vertical baseline and advance lines:

  1. In the main Font View window, go to View.
  2. Select Vertical to toggle the display mode from horizontal to vertical.

This view displays the glyphs as they will stack top-to-bottom, showing the top origin line and the vertical advance line.

Step 3: Set Custom Vertical Advance Widths

You can assign custom vertical advances using several methods depending on your workflow:

Method A: Using the Metrics Menu (Single or Multiple Glyphs)

  1. Select one or more glyphs in the main Font View.
  2. Go to Metrics in the top menu.
  3. Select Set VWidth....
  4. Enter your desired custom vertical advance value in font units.
  5. Click OK.

Method B: Using the Glyph Info Window (Per Glyph)

  1. Right-click the desired glyph in the Font View and select Glyph Info (or press Ctrl+I / Cmd+I).
  2. Go to the Size or Metrics tab.
  3. Locate the VWidth field and input your custom numerical value.
  4. Adjust the vertical origin offset if the glyph needs to be shifted relative to the top bearing.
  5. Click OK.

Method C: Using the Metrics Window (Visual Editing)

  1. Select the glyphs you want to adjust and go to Metrics > New Metrics Window.
  2. Change the view direction to vertical by clicking the vertical text icon in the toolbar or selecting View > Vertical.
  3. In the text field table at the bottom, edit the VWidth numeric cell directly.
  4. Alternatively, click and drag the bottom horizontal line representing the vertical advance boundary in the visual preview area.

Step 4: Verify and Export

  1. Test the alignment of stacked characters in the Metrics Window to verify spacing and aesthetics.
  2. Go to File > Generate Fonts... to export your OpenType (.otf) or TrueType (.ttf) font. FontForge will automatically compile your custom vertical values into the OpenType vmtx table.
