Toggle Point Coordinates in FontForge

This guide explains how to toggle the visual display of point coordinates in FontForge's Glyph Outline view. You will learn the exact menu option to show or hide numeric X and Y values directly on the canvas, how to read coordinates dynamically from the info bar, and how to inspect individual point coordinates with precision using the Point Info dialog.

Displaying Coordinates on the Canvas

To display coordinate labels next to every on-curve point and off-curve control handle directly in the glyph design window:

  1. Open your font project and double-click any glyph to enter the Glyph Outline View.
  2. Click the View menu in the top menu bar.
  3. Click Show Point Coordinates to toggle the feature on. A checkmark will appear next to the item when it is active.

When enabled, the canvas renders the exact integer (or decimal) \((X, Y)\) location beside each point. To hide the numbers again and reduce visual clutter, click View > Show Point Coordinates a second time to uncheck it.

Alternative Ways to Check Coordinates

If having numbers displayed next to every point crowds your workspace, FontForge provides less intrusive alternatives to inspect point positions:

  • The Coordinate Status Bar: Look at the top or bottom status bar of the Glyph Outline View. When you hover your cursor over the canvas, move a handle, or select a node, FontForge displays the active \(X\) and \(Y\) coordinates in real time alongside displacement values \((\Delta X, \Delta Y)\).
  • Point Info Dialog: Select any specific point, right-click it, and select Get Info (or press Ctrl + I on Windows/Linux, Cmd + I on macOS). This opens a window showing the point's exact base coordinates, incoming control points, and outgoing control points, where values can also be edited manually.
