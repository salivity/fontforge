Update Designer and Vendor URL in FontForge

Updating the designer and vendor URLs in FontForge is essential for embedding proper metadata and creator attribution directly into OpenType and TrueType fonts. This guide outlines the exact steps to locate and modify the OpenType Name Table fields responsible for the designer URL (Name ID 12) and vendor URL (Name ID 11) within the application's Font Info settings.

Step 1: Open the Font Info Window

  1. Launch FontForge and open your font file (.sfd, .ttf, or .otf).
  2. In the top menu bar, click on Element.
  3. Select Font Info from the drop-down menu (or use the shortcut Ctrl+Shift+F on Windows/Linux or Cmd+Shift+F on macOS).

Step 2: Navigate to TTF Names

  1. In the left-hand navigation pane of the Font Info dialog, locate the category titled TTF Names.
  2. Click on TTF Names to view the table of OpenType name records assigned to the font.

Step 3: Locate or Add the URL Records

FontForge stores web metadata using standard OpenType Name IDs:

  • Vendor URL: Name ID 11 (labeled as URL Vendor)
  • Designer URL: Name ID 12 (labeled as URL Designer)

To update existing entries:

  1. Scroll through the list in the TTF Names panel and find URL Vendor or URL Designer.
  2. Double-click the field value or select the row and click the Edit button.
  3. Enter your full website address (including https://).
  4. Click OK to save the value.

To add entries if they do not exist:

  1. Click the Add button at the bottom of the TTF Names panel.
  2. In the configuration dialog, set the language (typically English (US)).
  3. Choose the appropriate field name (URL Vendor or URL Designer) from the Name ID drop-down list.
  4. Input the desired URL into the string field.
  5. Click OK to add the entry to the list.

Step 4: Apply and Save

  1. Click OK at the bottom of the main Font Info window to commit the metadata changes.
  2. Save your FontForge source file (File > Save).
  3. Export the updated font binary by navigating to File > Generate Fonts... so the new metadata is compiled into your final .ttf or .otf file.
