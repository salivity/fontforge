Using Multi-Monitors with FontForge Efficiently

FontForge’s traditional multi-window architecture makes it exceptionally well-suited for multi-monitor workstations. Unlike modern unified-window applications, FontForge relies on independent, floating top-level windows for its primary workspaces, allowing type designers to separate font overviews, glyph vector editing, and live metrics testing across multiple displays to maximize productivity.

Why FontForge Excels on Multiple Displays

FontForge is built on a Multiple Document Interface (MDI) / Single Document Interface (SDI) hybrid model derived from X11 design principles. Every major functional component of the software opens as an autonomous window managed by your operating system, rather than being confined inside a single parent frame. This structure makes moving components across physical screens seamless without requiring nested detachments or third-party window managers.

Optimal Multi-Monitor Configuration

To achieve an efficient multi-monitor layout in FontForge, divide your tasks based on macro-level inspection and micro-level drafting:

  • Primary Display (Vector Editing): Dedicate your central monitor entirely to the Glyph Outline View. Vector drafting requires maximum screen real estate for bezier curve manipulation, node alignment, and extreme zooming. Keep your primary floating tool palettes (Tools, Layers, and Points) docked or grouped near the edges of this workspace.
  • Secondary Display (Overview & Metrics): Place the main Font View (the character map showing all glyphs) and the Metrics View on your secondary screen. The Metrics View allows you to test kerning and side-bearings across text strings in real time. Because changes made in the Glyph window on your primary display update instantaneously in the Metrics View on the secondary display, you can fine-tune vector shapes while continuously evaluating spacing and proportions without switching windows.

Practical Tips and Platform Considerations

  • Real-Time Kerning Feedback: Keep your Metrics window wide across your secondary screen. As you alter contours or advance widths in the primary monitor's Glyph window, the rendered text strings on your secondary screen will reflect these updates dynamically.
  • Display Scaling (DPI): If your setup pairs displays with mismatched resolutions (such as a 4K monitor alongside a 1080p monitor), FontForge's older GUI framework can sometimes experience scaling discrepancies on Windows or Linux. For optimal visual clarity, configure your operating system scaling factors to identical ratios or use displays with matching pixel densities.
  • Window Persistence: FontForge remembers window dimensions and placements across sessions. Once you set up your desired window distribution across your monitors, save your preferences via File > Preferences > Generic > SaveToPref so the application restores your layout upon restart.
