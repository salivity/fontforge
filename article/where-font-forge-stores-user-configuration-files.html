Where FontForge Stores User Configuration Files

FontForge stores its user preferences, shortcut mappings, and custom scripts in specific configuration directories that vary depending on your operating system. This guide outlines the exact file paths for Linux, macOS, and Windows, detailing where to find these configuration files so you can back them up, transfer them to a new machine, or manually edit them.

Linux and Unix-like Systems

On modern Linux distributions, FontForge adheres to the XDG Base Directory Specification, though legacy versions may use a hidden directory in the user's home folder.

  • Modern path: ~/.config/fontforge/
  • Legacy path: ~/.FontForge/

Within these directories, you will find files such as prefs (storing general settings) and hotkeys (custom keyboard shortcuts). Temporary autosave files are typically stored in ~/.FontForge/autosave/ or under the ~/.local/share/fontforge/ path.

macOS

On macOS, the location depends on whether you installed FontForge via the official application bundle, Homebrew, or MacPorts.

  • Standard / Bundle path: ~/.config/fontforge/
  • Alternative / Legacy path: ~/.FontForge/
  • Application Support path: ~/Library/Application Support/FontForge/

To navigate to these folders in Finder, press Cmd + Shift + G and paste the path (e.g., ~/.config/fontforge/).

Windows

On Windows, FontForge stores its configuration files inside the user's roaming application data folder or the user profile root.

  • Standard path: %APPDATA%\FontForge\ (typically resolves to C:\Users\<Username>\AppData\Roaming\FontForge\)
  • Alternative path: %USERPROFILE%\.FontForge\ (resolves to C:\Users\<Username>\.FontForge\)

You can quickly access this location by pressing Win + R, typing %APPDATA%\FontForge, and pressing Enter.

Key Configuration Files

Regardless of the operating system, the configuration directory typically contains the following core files:

  • prefs: Plaintext file containing general application preferences, including UI settings, default font formats, and grid configurations.
  • hotkeys: Defines user-defined keyboard shortcuts for FontForge commands.
  • autosave/: A folder containing emergency recovery files generated during unexpected application crashes.
